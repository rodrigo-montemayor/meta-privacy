Publicidad Vehículos Prueba

Política de privacidad

Última actualización: 2 de noviembre de 2026.

Esta política se refiere a la aplicación Publicidad Vehículos Prueba, utilizada para desarrollar y validar la integración publicitaria de Prime con las APIs de Meta sobre recursos autorizados.

Responsable y contacto

El responsable de esta aplicación de pruebas es Rodrigo Montemayor. Para consultas sobre privacidad, acceso, corrección o eliminación de datos, escribe a rodrigo.montemayor@34bits.com.

Información que se utiliza

Según los permisos concedidos por el administrador, las pruebas pueden utilizar:

  • Identificadores y nombres del usuario autorizante, las páginas y las cuentas publicitarias accesibles, sus permisos y su configuración técnica, como moneda, zona horaria y estado.
  • Credenciales de acceso a la API, imágenes y textos de prueba, así como identificadores, configuración y resultados de las operaciones publicitarias.
  • Respuestas técnicas y errores necesarios para diagnosticar el funcionamiento de la integración.

El alcance actual de estas pruebas no incluye la consulta de conversaciones privadas de Messenger ni la importación de contactos de Facebook.

Finalidad y servicios utilizados

La información se utiliza para comprobar accesos y probar la creación, consulta y gestión de imágenes, campañas, conjuntos de anuncios y creativos. No se utiliza para vender datos personales ni para elaborar perfiles comerciales de personas.

Las imágenes, los textos y los parámetros publicitarios se envían a Meta al ejecutar las operaciones autorizadas. Durante las pruebas se utilizan herramientas como Graph API Explorer y Postman para enviar solicitudes y revisar sus respuestas. Estos servicios aplican sus propias políticas de privacidad.

La información conservada por el responsable se limita a lo necesario para realizar y diagnosticar las pruebas; su acceso se limita a quienes intervienen de forma autorizada en ese trabajo.

Conservación de los datos

Los datos de prueba conservados por el responsable se mantienen mientras sean necesarios para validar o diagnosticar la integración. Cuando dejan de ser necesarios, se eliminan o anonimizan, salvo que exista una obligación de conservación aplicable.

Los activos creados dentro de Meta, como imágenes, campañas y anuncios, también quedan en la cuenta publicitaria correspondiente. Revocar el acceso de la aplicación no elimina automáticamente esos activos.

Solicitar acceso, corrección o eliminación

Toda persona cuyos datos sean tratados por esta aplicación puede solicitar información sobre ellos, su corrección o su eliminación escribiendo a rodrigo.montemayor@34bits.com. Indica que la solicitud corresponde a Publicidad Vehículos Prueba y proporciona información suficiente para identificar los datos o recursos relacionados. No envíes contraseñas ni tokens de acceso.

Antes de realizar cambios se podrá solicitar la información mínima necesaria para verificar la identidad o autorización del solicitante. El responsable atenderá la solicitud y comunicará el resultado por correo; si algún dato debe conservarse por una obligación aplicable, informará el motivo.

El administrador también puede revocar los permisos de la aplicación desde la configuración de su cuenta de Facebook para impedir nuevos accesos autorizados por esos permisos.

Visitas a esta página

Esta página no incorpora formularios, scripts de analítica, píxeles publicitarios ni cookies propias. Al alojarse en GitHub Pages, GitHub registra datos técnicos de las visitas, incluida la dirección IP, con fines de seguridad. Puedes consultar su política de privacidad.

El tratamiento realizado por Meta se describe en su política de privacidad.

Cambios en esta política

Si cambian las funciones de la aplicación o el uso de datos, esta política se actualizará para reflejarlo. La fecha al inicio del documento identifica la versión vigente.
